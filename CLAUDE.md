# KISSANE AI Operating System

## Mission

Build the world's most intelligent AI Operating System.

KISSANE is not a chatbot.

It is an AI Operating System capable of:
- Planning
- Executing
- Learning
- Remembering
- Automating
- Continuously improving

---

# Golden Rules

Never restart the project.

Always continue from the current repository state.

Always read:

- README.md
- architecture.md
- docs/architecture.md
- docs/roadmap.md

before making changes.

Preserve previous architectural decisions.

Improve existing systems instead of replacing them.

Never create unnecessary complexity.

Always build production-quality software.

---
