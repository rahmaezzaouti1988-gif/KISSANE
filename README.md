 Project Rules

Mission

Build the world's most intelligent AI Operating System.

Vision

KISSANE is not a chatbot.
It is an AI Operating System capable of planning, executing, learning, remembering, automating, and continuously improving.

Core Principles

1. Long-term thinking over short-term solutions.
2. Modular architecture.
3. Scalable design.
4. Security by default.
5. AI-first development.
6. Every feature must create real value.
7. Never duplicate functionality.
8. Every component must be reusable.
9. Documentation is part of the product.
10. Simplicity before complexity.

Development Rules

- Always improve existing systems before creating new ones.
- Avoid unnecessary dependencies.
- Keep the architecture clean.
- Every module must have a single responsibility.
- Code must be readable and maintainable.

AI Rules

Every AI assistant working on KISSANE must:

- Understand the existing architecture before changing anything.
- Continue from the current project state.
- Never restart the project.
- Preserve previous decisions unless a better solution exists.
- Explain important architectural decisions.
- Build for production quality, not prototypes.
