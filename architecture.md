# KISSANE Architecture

## Status

This document is the single source of truth for the architecture of KISSANE.

The implementation order is:

1. Core
2. Resilience Layer
3. Global Opportunity Platform
4. Value Capture Engine
5. Autonomous Company Builder
6. Portfolio Manager
7. Civilization Platform
8. Legacy & Evolution

No new component may be added unless it:
- Increases the overall capability of the system.
- Is reusable.
- Adds more value than complexity.
